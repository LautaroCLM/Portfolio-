Stock Management System

Sistema integral de gestión comercial e inventario sincronizado entre aplicación de escritorio (Electron) y plataforma web (Next.js) con base de datos centralizada en Supabase y persistencia local SQLite.

El Problema

Los comercios pequeños y medianos suelen depender de planillas de cálculo manuales o sistemas locales aislados en una única computadora. Esto genera inconsistencias en el stock al realizar ventas simultáneas, falta de acceso a métricas comerciales desde fuera del local y vulnerabilidad ante pérdidas de datos por fallas de hardware.

check_circle

La Solución

Desarrollé una plataforma híbrida que combina la velocidad operativa de un cliente de escritorio (Electron con SQLite) para la caja del negocio con una aplicación web en la nube (Next.js con Supabase/PostgreSQL) para supervisión remota, ventas online, gestión de inventario en tiempo real, administración de proveedores, finanzas y respaldos automatizados.

Ingeniería & Decisiones

Desafíos Técnicos

Desafío 01

Dualidad Desktop y Web

Problema: Permitir operar en la caja registradora con velocidad local sin perder sincronización remota.

Decisión: Combinar Electron con SQLite local y Supabase PostgreSQL para la nube.

Resultado: Operatividad ininterrumpida y sincronizada entre entornos.

Desafío 02

Consistencia de Stock

Problema: Evitar sobrentradas o discrepancias cuando se procesan ventas concurrentes.

Decisión: Implementar actualizaciones atómicas de inventario centralizadas en Supabase.

Resultado: Control exacto del inventario en tiempo real sin pérdida de datos.

Desafío 03

Resguardo de Datos

Problema: Proteger los registros comerciales locales ante fallas imprevistas de hardware.

Decisión: Crear un módulo integrado de backups automatizados y restauración.

Resultado: Respaldo seguro en 1 clic para la continuidad operativa del negocio.
